# 발행 일정 관리

여러 영상(또는 여러 채널)이 동시에 돌아가면 머리로는 못 잡는다. 캘린더 하나로 상태를 관리한다.

## 캘린더 형식 (`channel/CALENDAR.md`)

```markdown
# 발행 캘린더

## 이번 주 (YYYY-MM-DD ~)
| 발행일 | 제목/주제 | 상태 | 기획안 | 메모 |
|---|---|---|---|---|
| 07-10 | 클로드 코드 9가지 활용법 | 편집중 | plans/2026-07-07-클로드코드.md | 썸네일 A/B 준비됨 |

## 대기 중
| 목표일 | 제목/주제 | 상태 | 기획안 | 메모 |

## 발행 완료
| 발행일 | 제목 | 조회수 메모 | 링크 |

## 아이디어 보관함
- (아직 기획 전인 아이디어들)
```

상태 값: `아이디어 → 기획완료 → 촬영대기 → 촬영완료 → 편집중 → 발행준비 → 발행완료`

## 할 수 있는 일

1. **캘린더 만들기/보기**: 없으면 위 형식으로 생성. "이번 주 발행할 것과 다음 주 촬영할 것"을 물으면 해당 부분만 요약해서 답한다.

2. **상태 업데이트**: "OO 촬영 끝났어" → 상태 변경. `/video-plan`으로 기획안이 생기면 자동으로 '기획완료' 행 추가를 제안한다.

3. **아이디어 수집**: 사용자가 흘리듯 말한 아이디어("아 이거 영상 하면 되겠다"), 녹음 텍스트, 메모를 받으면 아이디어 보관함에 정리한다.

4. **주간 브리핑**: "이번 주 브리핑해줘" → 발행 예정, 밀린 것(목표일 지난 것), 파이프라인 현황(단계별 개수), 다음에 할 일 1가지 추천.

5. **정체 감지**: 캘린더를 열 때마다 오래 같은 상태에 머문 항목이 있으면 짚어준다. (예: "이 기획안은 2주째 촬영대기예요")

## 외부 연동 (선택)

- **노션 MCP가 연결되어 있으면**: 캘린더를 노션 데이터베이스로도 동기화해 준다.
- **구글 캘린더 MCP가 연결되어 있으면**: 촬영일·발행일을 캘린더 일정으로 등록해 준다.
- 연결이 안 되어 있으면: 마크다운 캘린더로 충분히 동작하며, 연동을 원하면 해당 MCP 설치를 안내한다.

## 주의

- 발행 완료된 영상은 완료 섹션으로 옮기고 지우지 않는다 — 나중에 `/channel-analysis`에서 성과 대조 자료가 된다.
