# 성과 리포트 (발행 후 루프 닫기)

만들고 올리는 것으로 끝나면 공식은 늙는다. 발행 후 성과를 기록하고, A/B 테스트에서 배운 것을 공식(FORMULA.md)에 되돌려 넣는다. 주 1회 추천.

## 진행 순서

1. **직전 데이터 보관**: `channel/videos.csv`가 있으면 비교용으로 스냅샷을 남긴다.
   ```
   mkdir -p channel/output/history
   cp channel/videos.csv channel/output/history/videos-$(date +%F).csv
   ```

2. **데이터 갱신**: 채널 URL은 `channel/BRAND.md`에서 찾고, 없으면 물어본 뒤 BRAND.md에 저장해 둘 것을 제안한다 (다음부터 안 물어보게).
   ```
   python3 scripts/channel_data.py <채널URL> --output channel/videos.csv --sort date
   ```

3. **성과 비교**: 새 CSV와 가장 최근 스냅샷(`channel/output/history/`에서 오늘 이전 날짜 중 최신)을 영상ID로 대조한다.
   - **새로 발행된 영상**: 스냅샷에 없던 영상. 현재 조회수를 채널 평균 대비 %로 표시.
   - **조회수 증가 TOP 5**: 증가분 기준. 옛 영상이 갑자기 오르는 **역주행**이 있으면 강조 — 그 주제는 재활용 후보다.
   - **채널 전체**: 총 조회수 증가분.
   - 스냅샷이 없는 첫 리포트면 비교 없이 현재 상태(최근 영상 성과 vs 평균)만 브리핑하고, "다음 리포트부터 변화 추적이 시작된다"고 알려준다.

4. **스튜디오 데이터 (선택)**: 노출 클릭률(CTR)·시청 지속 시간은 공개 데이터에 없다. 유튜브 스튜디오 화면을 캡처해서 주면(파일을 `channel/output/`에 넣거나 채팅에 첨부) 이미지를 읽어 분석에 포함한다. 없으면 조회수 기반으로만 진행한다.

5. **A/B 테스트 결과 기록**: 진행 중인 썸네일 A/B가 있는지 확인한다 (`channel/plans/`의 기획안, `channel/CALENDAR.md`의 메모).
   - 있으면 결과(승자)를 물어본다. 유튜브 스튜디오의 '테스트 및 비교' 결과 화면 캡처를 받으면 직접 읽는다.
   - 승자가 정해졌으면 `channel/FORMULA.md`에 **검증 기록**을 덧붙인다:
     ```markdown
     ## 검증 기록 (A/B 테스트 결과)
     | 날짜 | 영상 | 이긴 문구 (심리 공식) | 진 문구 (심리 공식) | 배운 것 |
     ```
     기존 공식 내용은 지우지 않는다. 같은 심리 공식이 2번 이상 이기면 썸네일 공식 본문에 "검증됨 ✓"을 표시한다.

6. **리포트 저장**: `channel/reports/YYYY-MM-DD-리포트.md`로 저장한다. 구성:
   - 이번 주 발행 영상과 성과 (평균 대비)
   - 조회수 증가 TOP 5 + 역주행 감지
   - A/B 테스트 결과와 배운 것
   - **다음 액션 3가지** — 데이터에 근거한 구체적 제안 (예: "역주행 중인 OO 주제로 쇼츠 추출", "이긴 손실 공식으로 다음 썸네일")

7. **캘린더 정리**: `channel/CALENDAR.md`의 "발행 완료" 섹션에 조회수 메모를 업데이트한다 (`/schedule` 형식 유지).

## 주의

- **발행 48시간 이내 영상은 판단 유보.** "아직 이르다"고 표시하고 다음 리포트에서 다시 본다.
- 조회수 절대치가 아니라 **채널 평균 대비**로 해석한다. 구독자 1만 채널의 5천 회와 100만 채널의 5천 회는 다르다.
- 공개 데이터로는 CTR·시청 지속을 알 수 없다 — **추측해서 말하지 않는다.** 모르는 건 모른다고 하고 스튜디오 캡처를 요청한다.
- FORMULA.md를 업데이트할 때 기존 분석을 덮어쓰지 않는다. 날짜와 함께 기록을 누적한다 — 공식이 어떻게 진화했는지가 자산이다.
