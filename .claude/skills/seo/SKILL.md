# 설명란 · 태그 · 챕터 · 고정댓글 (SEO 세팅)

업로드 직전 마지막 세팅. 검색과 탐색 노출에 걸리도록 채운다.

## 진행 순서

1. **재료 자동 탐색**: 사용자가 파일을 지정하지 않아도 알아서 찾는다.
   - `channel/plans/`에서 가장 최근 기획안과 그에 딸린 `-대본.md`를 찾는다 (접미사 붙은 산출물 파일은 기획안 후보에서 제외).
   - 자막(SRT)은 `channel/output/`에서 찾는다. 후보가 여럿이거나 주제가 안 맞으면 목록을 보여주고 고르게 한다.
   - `channel/BRAND.md`도 읽는다 (말투, 링크 블록).
   - 재료가 아무것도 없으면 영상 주제와 핵심 내용을 물어본다.
   - **타임코드 정확도 순위: SRT(실제 영상 기준) > 대본(추정치)**. 내용 파악은 대본이 더 좋으니 둘 다 있으면 둘 다 쓴다.

2. **설명란 작성**:
   - **첫 2줄에 핵심 키워드**를 자연스럽게 포함 — 접힌 상태에서 보이는 부분이 검색에 제일 중요하다.
   - 3~5줄: 영상이 답하는 질문, 얻어가는 것 요약.
   - 사용자의 링크 블록(홈페이지, 커뮤니티, 제품 등)이 BRAND.md에 있으면 포함한다.

3. **챕터 타임스탬프**:
   - 자막(SRT)이 있으면 내용 전환점을 찾아 정확한 타임코드로 챕터를 만든다.
   - 대본만 있으면 초안을 자동으로 뽑는다:
     ```
     python3 scripts/script_timer.py channel/plans/<기획안이름>-대본.md --chapters
     ```
     그리고 "편집 후 실제 시간으로 조정 필요"라고 표시한다.
   - 형식: `00:00 인트로` 부터 시작 (첫 챕터가 00:00이어야 유튜브가 인식한다). 챕터 제목은 '훅'·'약속' 같은 내부 용어 대신 **시청자가 검색할 키워드**로 다듬는다.

4. **태그 5개**: 핵심 키워드 1~2개 + 연관 검색어 2~3개. 조합은 넓은 것부터 좁은 것 순서로.

5. **고정댓글 1개**: 다음 중 상황에 맞는 것으로.
   - 시청자에게 던지는 질문 (댓글 참여 유도)
   - 영상 속 자료/링크 정리 (CTA)
   - 다음 영상 예고
   BRAND.md의 말투로 쓴다.

6. **저장 & 전달**: 결과를 `channel/plans/<기획안이름>-SEO.md`로 저장하고 (기획안이 없으면 `YYYY-MM-DD-<주제>-SEO.md`), 복사해서 바로 붙여넣을 수 있게 각 항목을 코드 블록으로도 보여준다. 기획안이 있으면 상태를 `발행준비`로 바꾸고, `channel/CALENDAR.md`가 있으면 캘린더도 같이 갱신할지 물어본다.

## 주의

- 키워드를 어색하게 욱여넣지 않는다. 유튜브는 검색엔진이기 전에 시청자가 읽는 곳이다.
- 태그 스팸(연관 없는 인기 키워드)은 하지 않는다.
- 다국어 자막(`/subtitle`)이 있는 영상이면 설명란에도 영어 한 줄 요약을 추가하는 것을 제안한다.
