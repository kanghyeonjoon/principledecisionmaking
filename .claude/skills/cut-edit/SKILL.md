# 컷편집 (무음·더듬 구간 자동 감지)

편집에서 제일 오래 걸리는 무음 걷어내기를 자동화한다. 한 영상당 5~6시간 걸리던 후반작업을 줄이는 핵심.

## 진행 순서

1. **파일 받기**: 영상 파일 경로를 받는다. ffmpeg가 없으면 설치해 준다.

2. **무음 감지 실행**:
   ```
   python3 scripts/silence_detect.py <영상경로>
   ```
   - 결과: `channel/output/silences.csv` (잘라낼 구간 타임코드 목록)
   - 감지가 너무 많거나 적으면 기준을 조절한다: `--noise -30`(더 민감) / `--min-silence 1.0`(더 보수적)

3. **결과 브리핑**: 무음 구간 수, 총 몇 초가 잘리는지, 편집 후 예상 길이를 알려준다.

4. **다음 행동을 고르게 한다**:
   - **A. 자동으로 잘라낸 영상 받기**: 
     ```
     python3 scripts/silence_detect.py <영상경로> --cut channel/output/편집본.mp4
     ```
     말이 뚝 끊기지 않게 앞뒤 0.15초 여유를 두고 자른다 (`--padding`으로 조절).
   - **B. 타임코드 목록만 받아서 편집 프로그램에서 직접**: 프리미어 프로 / 캡컷 / 베가스 어디서든 CSV의 타임코드를 보면서 자르면 된다. 사용자가 쓰는 편집 프로그램에 맞는 적용 방법을 안내한다.

5. **더듬는 구간**: 무음 감지로는 "어…", "음…" 같은 필러는 안 잡힌다. 원하면:
   - `/subtitle`로 자막을 먼저 만들고, 자막 텍스트에서 필러·반복 구간의 타임코드를 찾아 잘라낼 목록에 추가해 준다.

## 주의

- 원본 파일은 절대 덮어쓰지 않는다. 출력은 항상 `channel/output/` 아래 새 파일로.
- 인터뷰·대화 영상은 무음이 자연스러운 리듬일 수 있다. `--min-silence 1.5` 정도로 보수적으로 시작하라고 권한다.
- 자동 컷은 재인코딩이라 화질이 아주 미세하게 달라질 수 있다. 최종 마스터는 편집 프로그램에서 하는 걸 권하되, 유튜브 업로드용으로는 충분하다고 안내한다.
