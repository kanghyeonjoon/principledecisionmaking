# 댓글 분석 (반응 · 아이디어 · 답글 초안)

댓글은 시청자가 직접 써 주는 다음 영상 기획서다. 발행 1~2일 뒤에 돌리면 가장 효과가 좋다.

## 진행 순서

1. **대상 영상 정하기**: 사용자가 URL을 주면 그대로 쓴다. "최근 영상"이라고 하면 `channel/videos.csv`에서 최신 영상의 URL을 찾는다 (CSV가 없으면 URL을 물어본다).

2. **댓글 수집**:
   ```
   python3 scripts/comments_data.py <영상URL>
   ```
   → `channel/output/comments/<영상ID>.csv` 저장 (인기순, 답글 포함 200개).
   댓글이 아주 많은 영상이면 `--limit 500`으로 늘린다. yt-dlp가 없으면 설치해 준다 (`pip install yt-dlp`).

3. **분석**: CSV를 읽고 4가지를 뽑는다.
   - **전체 반응 요약**: 분위기(긍정/부정/혼합)와 좋아요 TOP 5 댓글. 어떤 대목이 반응을 만들었는지.
   - **자주 묻는 질문(FAQ)**: 여러 명이 반복해서 묻는 것. 각 질문에 몇 명이 물었는지 표시.
   - **다음 영상 아이디어**: "OO도 다뤄주세요", "OO은 어떻게 해요?" 같은 요청. 각 아이디어에 근거가 된 댓글을 인용으로 붙인다 — 시청자가 직접 말해준 수요라는 게 핵심이다.
   - **개선 피드백**: 소리·편집·길이·속도 등에 대한 지적. 여러 명이 말한 것만 (한 명의 취향은 노이즈일 수 있다).

4. **답글 초안**: 답글 가치가 큰 댓글 5~10개를 골라 `channel/BRAND.md`의 말투로 답글 초안을 쓴다.
   - 우선순위: 좋아요 많은 댓글 > 질문 댓글 > 정성 긴 댓글
   - 고정댓글 후보나 하트 누를 댓글도 추천한다.
   - **게시는 사용자가 직접 한다.** 초안 옆에 원댓글을 인용해서 복붙하기 쉽게 정리한다.

5. **저장**: 분석 결과를 `channel/comments/YYYY-MM-DD-<주제>.md`로 저장한다. 구성:
   - 영상 정보 (제목, URL, 분석일, 댓글 수)
   - 반응 요약 / FAQ / 다음 영상 아이디어 / 개선 피드백 / 답글 초안

6. **환류**: 발굴한 영상 아이디어를 `channel/CALENDAR.md`의 "아이디어 보관함"에 추가할지 제안한다 (`/schedule` 형식 유지). FAQ는 다음 `/video-plan` 때 참고 자료가 된다.

## 주의

- **악플과 건설적 비판을 구분한다.** 비판에는 담담한 답글 초안을 제안할 수 있지만, 악플에는 답글 초안을 만들지 않는다 (무시가 정답인 경우가 많다고 안내).
- 댓글이 꺼져 있거나 없는 영상이면 에러로 멈추지 말고 상황을 설명해 준다.
- 아이디어를 뽑을 때 `channel/BRAND.md`의 방향과 맞는지 확인한다. 브랜드와 안 맞는 요청은 "요청은 있지만 채널 방향과 다름"으로 따로 표시한다.
