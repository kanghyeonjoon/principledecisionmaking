# 경쟁 채널 · 레퍼런스 분석

경쟁 채널을 일일이 들여다보는 대신, 데이터로 트렌드와 기회를 잡는다. 결과는 `channel/COMPETITORS.md`.

## 진행 순서

1. **채널 목록 받기**: 사용자에게 경쟁/레퍼런스 채널 링크를 받는다 (여러 개 가능). 정리해 둔 목록이 없다고 하면, 사용자의 분야를 물어 함께 후보를 찾아본다.

2. **채널별 데이터 추출**: 채널마다 최근 25편 내외를 추출한다.
   ```
   python3 scripts/channel_data.py <채널URL> --limit 25 --sort date --output channel/competitors/<채널이름>.csv
   ```

3. **채널별 분석**: 각 CSV를 읽고 정리한다.
   - 지금 다루는 주제·소재 리스트업 (제목에서 주제 분류)
   - 최근 잘 터진 영상 (그 채널 평균 대비 2배 이상)
   - 업로드 주기와 영상 길이 경향

4. **교차 분석 — 여기가 핵심**:
   - **공통 인기 소재**: 여러 경쟁 채널에서 동시에 잘되는 주제 = 지금 시장의 트렌드
   - **갭 분석**: `channel/videos.csv`(내 채널 데이터)와 대조해서 **"경쟁 채널들은 다루는데 나만 안 다룬 주제"** 목록을 만든다. 내 채널 데이터가 없으면 `/channel-analysis`를 먼저 권한다.
   - 잘 터진 경쟁 영상 3~5개는 썸네일도 내려받아 직접 보고 분석한다 (channel-analysis와 같은 curl 방식).

5. **저장**: `channel/COMPETITORS.md`로 저장. 구성:
   - 채널별 요약 (한 채널당 5줄 이내)
   - 공통 트렌드 주제 TOP 5
   - **내가 안 다룬 주제 목록** (각각에 "내 브랜드에 맞게 다루려면 이런 각도로" 제안 포함)
   - 다음 기획에 바로 쓸 소재 3개 추천

6. **마무리**: 갭 목록을 브리핑하고 `/video-plan`(기획안 만들기)을 추천한다.

## 주의

- 갭 주제를 그대로 베끼라고 제안하지 않는다. 반드시 `channel/BRAND.md`의 포지셔닝에 맞는 **내 각도**를 함께 제안한다.
- 채널 추출이 실패하면 (비공개, 주소 오타 등) 해당 채널만 건너뛰고 계속 진행한다.
