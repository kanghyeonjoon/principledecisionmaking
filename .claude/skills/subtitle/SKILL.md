# 자막 생성 + 다국어 번역

브루(Vrew) 없이 자막을 만든다. 같은 위스퍼 엔진을 직접 돌리는 것이라 결과 품질은 같고, 후처리는 더 좋다.

## 진행 순서

1. **자막 생성**: 영상 파일 경로를 받아 실행. whisper/ffmpeg가 없으면 설치해 준다 (`pip install openai-whisper`).
   ```
   python3 scripts/whisper_subtitles.py <영상경로> --model medium
   ```
   - 한국어는 `--model medium` 권장 (기본 small은 빠르지만 오타가 더 있음)
   - 결과: `channel/output/subtitles/<이름>.srt`

2. **맥락 단위 줄바꿈 다듬기**: 생성된 SRT를 읽고 다듬는다.
   - 단순 글자 수가 아니라 **의미 단위**로 줄을 나눈다. 조사나 어미에서 어색하게 끊긴 줄을 병합/분리.
   - 병합할 때는 첫 블록의 시작 타임코드와 마지막 블록의 끝 타임코드를 쓴다. **타임코드를 지어내지 않는다.**
   - 명백한 오타(고유명사, 전문용어)를 고친다. 애매한 건 사용자에게 물어본다.
   - 한 줄 길이는 화면 기준 최대 20자 안팎.
   - 다듬은 버전은 `<이름>.ko.srt`로 저장 (원본 보존).

3. **다국어 번역** (요청 시): 언어별로 번역 SRT를 만든다.
   - **타임코드는 그대로**, 텍스트만 번역한다 → 어떤 언어든 싱크가 딱 맞는다.
   - 직역이 아니라 그 언어 시청자에게 자연스러운 자막 번역체로.
   - 파일명: `<이름>.en.srt`, `<이름>.ja.srt`, `<이름>.id.srt`, `<이름>.th.srt` 등
   - 긴 영상이면 언어당 파일을 나눠 처리하지 말고, 블록 단위로 성실하게 끝까지 번역한다.

4. **업로드 안내**: 유튜브 스튜디오 → 자막(또는 언어) 탭 → 언어 추가 → 파일 업로드. 
   - 해외 시청자가 많아질 수 있는 분야(스포츠, 요리, 음악 등)는 영어+동남아 언어를 추천한다.
   - 채널을 꾸준히 운영하면 자막 탭이 '언어' 탭으로 바뀌고 썸네일도 언어별로 넣을 수 있게 된다는 것도 알려준다.

## 주의

- SRT 형식을 엄격히 지킨다: 번호, `HH:MM:SS,mmm --> HH:MM:SS,mmm`, 텍스트, 빈 줄.
- 원본 whisper 출력은 남겨두고 항상 새 파일로 저장한다.
