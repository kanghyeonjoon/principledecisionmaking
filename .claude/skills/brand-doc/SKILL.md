# 브랜드 문서 만들기

사용자의 채널을 한 문장으로 정의하고, 이후 모든 기획·대본·썸네일의 기준이 될 `channel/BRAND.md`를 만든다.

## 진행 순서

1. **기존 문서 확인**: `channel/BRAND.md`가 이미 있으면 읽고, 새로 만들지 업데이트할지 물어본다.

2. **채널 정보 수집**: 사용자에게 채널 링크를 물어본다. 링크를 주면:
   - `python3 scripts/channel_data.py <채널URL> --limit 50` 으로 영상 목록을 가져온다 (yt-dlp가 없으면 설치를 제안).
   - 조회수 상위 5개와 하위 5개 영상 제목을 파악해 둔다.
   - 채널이 아직 없거나 링크를 안 주면 이 단계는 건너뛴다.

3. **인터뷰 진행**: `templates/BRAND_TEMPLATE.md`의 도널드 밀러 8요소를 기준으로 사용자를 인터뷰한다.
   - **한 번에 한 질문씩** 묻는다. 8개를 한꺼번에 쏟아내지 않는다.
   - 사용자가 녹음을 텍스트로 붙여넣거나 길게 말하면, 거기서 8요소에 해당하는 내용을 알아서 분류하고 **비어 있는 요소만** 추가로 묻는다.
   - 답이 추상적이면 구체화 질문을 한 번 더 한다. (예: "직장인이요" → "몇 년차, 어떤 고민을 하는 직장인인가요?")

4. **한 문장 컨셉 도출**: 인터뷰 내용으로 다음 공식을 채운다.
   > [타겟]이 [문제]를 겪을 때, [경쟁자들]과 달리 [나만의 방법]으로 돕는다.
   
   2~3개 버전을 제안하고 사용자가 고르게 한다.

5. **문서 저장**: `templates/BRAND_TEMPLATE.md` 양식으로 `channel/BRAND.md`에 저장한다 (`mkdir -p channel` 먼저). 잘된 영상/안 된 영상 목록도 참고 데이터 섹션에 채운다.

6. **마무리**: 문서 요약을 보여주고, 다음 단계로 `/channel-analysis`(내 채널 분석)를 추천한다.

## 주의

- 사용자의 말을 그대로 받아적지 말고, 브랜딩 문서답게 다듬되 사용자의 표현과 말투는 살린다.
- 8요소 중 "하지 않는 것(금지 목록)"은 꼭 채운다 — 이후 썸네일·제목 생성 시 필터로 쓰인다.
