# 워크플로우 상세 가이드

이 툴킷의 사상: **감이 아니라 데이터로, 일반론이 아니라 내 브랜드로.**

모든 산출물은 ① 브랜드 문서(내가 누구인지) ② 내 채널 공식(뭐가 먹혔는지) ③ 경쟁 분석(시장이 뭘 원하는지) 세 가지에 근거해서 만들어집니다. 이 세 문서 없이 "기획안 만들어줘"라고 하는 것과, 만들고 나서 하는 것은 결과 차이가 큽니다.

## 0단계 — 마인드셋

- **도메인 전문가는 당신입니다.** 클로드는 당신의 디테일(경험, 숫자, 사례)을 따라올 수 없습니다. 클로드가 하는 건 그 디테일을 끌어내고, 구조화하고, 반복 작업을 대신하는 것.
- **타이핑보다 녹음.** 인터뷰 질문에 답할 때는 말로 녹음하고 텍스트로 변환해서 붙여넣는 게 훨씬 빠르고 디테일이 삽니다. (아이폰 음성 메모 → 받아쓰기, 또는 클로바노트 등)
- **한 명을 설득한다.** 모두에게 보여주는 게 아니라, 브랜드 문서에 정의한 단 한 명에게 말합니다.

## 1단계 — 채널 세팅 (처음 한 번, 약 1~2시간)

### `/brand-doc` 브랜드 문서
채널을 한 문장으로 정의합니다:
> [타겟]이 [문제]를 겪을 때, [경쟁자들]과 달리 [나만의 방법]으로 돕는다.

클로드가 도널드 밀러 8요소로 인터뷰를 진행합니다. 질문이 뜨면 녹음으로 답하세요.

### `/channel-analysis` 내 채널 분석
- 전체 영상의 조회수·날짜·길이를 표로 추출 (유튜브 스튜디오 데이터 전수)
- 잘된 영상 TOP 5의 썸네일·제목·대본 도입부를 분석해 **내 채널의 성공 공식** 추출
- "힘 빼고 했는데 터진" 영상의 비밀이 데이터로 보입니다.

### `/competitor-analysis` 경쟁 채널 분석
- 경쟁/레퍼런스 채널들의 최근 25편을 전수 추출
- 공통 트렌드 + **경쟁자는 다루는데 나만 안 다룬 주제(갭)** 발굴
- 유료 분석 프로그램이 하는 일이 이것입니다. 결제할 필요 없습니다.

## 2단계 — 영상 1편 만들기 (매번)

```
/video-plan → 질문 6개에 녹음으로 답변 → /script → 촬영
→ /cut-edit → /subtitle → /thumbnail → /seo → 업로드 → /shorts
```

| 단계 | 무엇을 | 시간 절약 포인트 |
|---|---|---|
| `/video-plan` | 썸네일·제목 후보, 인트로 30초, 질문지 6개 | 기획 회의 대체 |
| `/script` | 내 말투·구조 그대로 대본 완성 | 대본 작성 반나절 → 30분 |
| `/cut-edit` | 무음·더듬 구간 타임코드 or 자동 컷 | 컷편집 5~6시간 → 검수만 |
| `/subtitle` | SRT 자막 + 다국어 번역 자막 | 자막 작업 + 해외 유입 |
| `/thumbnail` | 심리 공식 기반 30개 후보 → A/B 2개 조 | 썸네일 고민 |
| `/seo` | 설명란·챕터·태그·고정댓글 | 업로드 세팅 |
| `/shorts` | 롱폼 1편 → 쇼츠 5개+ | 원소스 멀티유즈 |

### 라이브 방송을 한다면
라이브 종료 후 자동 저장된 영상(비공개)을 다운받아 `/cut-edit` → `/subtitle` → 롱폼으로 발행하는 흐름이 가장 효율이 좋습니다.

## 3단계 — 꾸준히 (주 1회)

### `/schedule` 발행 캘린더
- 아이디어 → 기획 → 촬영 → 편집 → 발행 파이프라인을 한 눈에
- "이번 주 브리핑해줘" 한마디로 발행 예정·밀린 것·다음 할 일 확인
- 노션/구글 캘린더 MCP를 연결하면 그쪽으로도 동기화

### 월 1회 재분석
`/channel-analysis`를 다시 돌려서 공식(FORMULA.md)을 업데이트하세요. 채널이 크면서 먹히는 공식도 변합니다.

## 남는 시간에 할 일

자동화로 아낀 시간은 기계가 못 하는 두 가지에 쓰세요:
1. **기획의 디테일** — 내 경험과 사례를 더 깊게
2. **팬덤과의 소통** — 댓글, 라이브, 커뮤니티
