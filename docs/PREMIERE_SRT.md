# 프리미어 프로에서 자막(SRT) 내보내기

`/shorts`(쇼츠 추출)와 `/seo`(챕터 타임스탬프)는 "몇 분 몇 초에 어떤 말이 나오는지" 적힌
**자막(SRT) 파일**을 재료로 씁니다. 프리미어 프로에서 편집한다면 별도 자막 프로그램 없이
아래 방법으로 SRT를 내보내면 됩니다.

## A. 이미 자막 작업을 했다면 (시퀀스에 캡션이 있는 경우)

1. 상단 메뉴 **창(Window) → 텍스트(Text)** 패널 열기
2. **캡션(Captions)** 탭에서 내보내기 버튼(↓ 모양) 클릭
3. **SRT 파일로 내보내기(Export to SRT file)** 선택 → 저장

## B. 자막 작업을 안 했다면 (받아쓰기부터)

1. **창(Window) → 텍스트(Text)** 패널 → **받아쓰기(Transcript)** 탭
2. **시퀀스 받아쓰기(Transcribe sequence)** 클릭 — 언어는 한국어로
3. 받아쓰기가 끝나면 **캡션 만들기(Create captions)** 클릭 (스타일은 아무거나, SRT 추출용이라 상관없음)
4. 위 A의 순서대로 캡션 탭에서 SRT로 내보내기

## 저장 위치와 사용법

- 저장 위치는 아무 곳이나 괜찮지만 `channel/output/` 폴더를 추천합니다.
  예: `channel/output/2026-07-07-주제.srt`
- 저장했으면 클로드에게 이렇게 말하면 됩니다:
  > "쇼츠 잘라줘. 자막은 channel/output/2026-07-07-주제.srt야"
  > "SEO 세팅해줘. 자막 파일 여기 있어: …"

## ⚠️ 주의: 시간 기준

SRT의 타임코드는 **편집이 끝난 시퀀스 기준**입니다.
- 받아쓰기·SRT 내보내기는 **컷편집을 다 끝낸 뒤에** 하세요. 내보낸 다음에 다시 자르면 시간이 어긋납니다.
- 쇼츠를 실제 클립으로 잘라낼 때도 **같은 편집 완료본**(최종 내보낸 영상 파일)을 써야 합니다.
