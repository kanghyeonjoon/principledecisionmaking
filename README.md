# 🎬 유튜브 크리에이터를 위한 클로드 코드 툴킷

코딩 지식 없이 클로드 코드(Claude Code)로 유튜브 채널 운영 전 과정을 자동화하는 툴킷입니다.

**브랜딩 → 채널 분석 → 기획 → 대본 → 썸네일 → 편집/자막 → 쇼츠/SEO → 일정 관리**

이 리포지토리를 클론하고 클로드 코드를 켜면, 슬래시 커맨드로 아래 작업을 바로 시작할 수 있습니다.

## 🚀 시작하기

```bash
git clone <이 리포지토리 주소>
cd principledecisionmaking
claude
```

클로드 코드가 켜지면 `/brand-doc` 이라고 입력해 보세요. 브랜드 문서 만들기부터 시작됩니다.

> 채널 데이터 수집, 자막 생성, 컷편집 기능을 쓰려면 무료 도구(yt-dlp, ffmpeg, whisper) 설치가 필요합니다.
> 설치 방법은 [docs/INSTALL.md](docs/INSTALL.md)를 참고하세요. 클로드에게 "설치 도와줘"라고 해도 됩니다.

## 📋 스킬(슬래시 커맨드) 목록

| 커맨드 | 하는 일 | 필요한 도구 |
|---|---|---|
| `/brand-doc` | 도널드 밀러 8요소 인터뷰로 **브랜드 문서** 생성 | 없음 |
| `/channel-analysis` | 내 채널 전체 영상 데이터 추출 + **잘된 영상 패턴 분석** | yt-dlp |
| `/competitor-analysis` | 경쟁 채널 최근 영상 분석 + **내가 안 다룬 주제(갭)** 발굴 | yt-dlp |
| `/video-plan` | 브랜드+분석 기반 **영상 기획안** (썸네일·제목 후보, 인트로 30초, 질문지 6개) | 없음 |
| `/script` | 잘된 영상들의 **대본 골격 추출** → 그 구조로 새 대본 작성 | 없음 |
| `/thumbnail` | 5대 심리 공식 기반 **썸네일 문구 30개** + A/B 테스트 조 구성 | 없음 |
| `/cut-edit` | 영상에서 **무음·더듬 구간 자동 감지** → 컷편집 타임코드 목록 | ffmpeg |
| `/subtitle` | **Whisper 자막(SRT) 생성** + 맥락 단위 줄바꿈 + 다국어 번역 자막 | ffmpeg, whisper |
| `/shorts` | 롱폼 1편에서 **쇼츠 5개 이상 추출** (타임코드 + 훅 + 세로 자막) | ffmpeg(잘라낼 때만) |
| `/seo` | **설명란·태그·챕터 타임스탬프·고정댓글** 한 번에 생성 | 없음 |
| `/comments` | 댓글 수집·분석 → **FAQ·다음 영상 아이디어·답글 초안** | yt-dlp |
| `/report` | 발행 후 **성과 리포트** + A/B 테스트 승자를 공식에 기록 | yt-dlp |
| `/schedule` | 기획→촬영→발행 **일정 관리** (발행 캘린더) | 없음 |

## 🗺️ 추천 워크플로우

### 처음 한 번만 (채널 세팅)

1. `/brand-doc` — 내 채널이 한 문장으로 뭔지 정리. 모든 산출물의 기준이 됩니다.
2. `/channel-analysis` — 내 채널에서 잘된 영상의 썸네일·제목·대본 공식 추출.
3. `/competitor-analysis` — 경쟁 채널이 뭘 다루는지, 내가 놓친 주제가 뭔지 파악.

### 영상 만들 때마다

4. `/video-plan` — 기획안 생성 (썸네일·제목 후보 + 인트로 + 나에게 던지는 질문 6개)
5. `/script` — 질문에 답한 내용(녹음→텍스트)으로 내 톤의 대본 완성
6. 촬영 🎥
7. `/cut-edit` — 무음·더듬 구간 타임코드 뽑아서 편집 시간 단축
8. `/subtitle` — 자막 자동 생성 + 영어·일본어 등 다국어 자막
9. `/thumbnail` — 썸네일 문구 30개 → 마음에 드는 것으로 A/B 테스트
10. `/seo` — 설명란·태그·고정댓글 세팅
11. `/shorts` — 롱폼에서 쇼츠 5개 추출해서 추가 유입 만들기

### 올리고 나서

12. `/comments` — 발행 1~2일 뒤 댓글에서 반응·질문·다음 영상 아이디어 수집 + 답글 초안
13. `/report` — 주 1회 성과 확인, 썸네일 A/B 승자를 성공 공식(FORMULA.md)에 기록

### 꾸준히

14. `/schedule` — 이번 주 발행할 것, 다음 주 촬영할 것 관리

## 📁 폴더 구조

```
├── .claude/skills/    # 슬래시 커맨드 (스킬) 정의
├── scripts/           # 실제 실행되는 자동화 스크립트 (Python)
├── templates/         # 브랜드 문서·기획안·썸네일 공식 템플릿
├── docs/              # 설치 가이드, 워크플로우 상세 설명
└── channel/           # 내 채널 데이터가 쌓이는 곳 (git에 올라가지 않음)
    ├── BRAND.md           # 브랜드 문서
    ├── FORMULA.md         # 내 채널의 성공 공식
    ├── COMPETITORS.md     # 경쟁 채널 분석
    ├── SCRIPT_STRUCTURE.md # 대본 골격
    ├── CALENDAR.md        # 발행 캘린더
    ├── plans/             # 영상별 기획안
    ├── comments/          # 영상별 댓글 분석
    └── reports/           # 발행 후 성과 리포트
```

`channel/` 폴더는 `.gitignore`에 등록되어 있어서 **개인 채널 데이터가 공개 리포에 올라가지 않습니다.**

## ❓ 자주 묻는 질문

**Q. API 키가 필요한가요?**
아니요. 채널 데이터는 yt-dlp(무료 오픈소스)로 수집하기 때문에 유튜브 API 키가 필요 없습니다.

**Q. 프로그램 설치가 어려워요.**
클로드 코드에게 "yt-dlp 설치해줘", "ffmpeg 설치해줘"라고 하면 알아서 설치해 줍니다.

**Q. 어떤 요금제가 필요한가요?**
클로드 코드는 Claude 유료 플랜(Pro 이상)에서 사용할 수 있습니다.

**Q. 노션이나 구글 캘린더 연동은요?**
`/schedule`은 기본적으로 마크다운 캘린더로 동작합니다. 노션/구글 캘린더 MCP를 연결하면 클로드가 그쪽에도 정리해 줍니다. (docs/WORKFLOW.md 참고)
